# Cutlass

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Português](README.pt-BR.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Русский](README.ru.md) · [العربية](README.ar.md) · **हिन्दी** · [Bahasa Indonesia](README.id.md)

सबके लिए मुफ़्त ऑल-इन-वन वीडियो संपादक, कुछ भी बनाने के लिए।

Cutlass में वीडियो बनाने के लिए जो चाहिए वह सब है, AI सहित। लचीला संपादन, और एक सहायक जिससे आप बात कर सकते हैं। जो वीडियो मन में है, वही बनाएँ।

फ़ुटेज, ऑडियो और छवियाँ लाएँ। उन्हें कई ट्रैक वाली टाइमलाइन पर ट्रिम करें, बाँटें और सजाएँ। पाठ, स्टिकर, आकार, प्रभाव और ट्रांज़िशन जोड़ें। रंग, गति और क्रॉप समायोजित करें, और कीफ़्रेम से एनिमेट करें। चलाएँ, फिर तैयार वीडियो निर्यात करें।

सरल शुरुआत करें, या आगे बढ़ें। वही संपादक एक तेज़ कट और एक सावधानी भरा कट दोनों संभालता है।

आप यह भी कह सकते हैं कि आप क्या चाहते हैं। संपादन को सादी भाषा में बताएँ, और Cutlass उसे टाइमलाइन पर बना देता है, जहाँ आप उसे बदल सकते हैं या पूर्ववत कर सकते हैं। जब आप खुद काम करते हैं, संपादक उतना ही पूरा होता है।

आज [रिलीज़](https://github.com/1mrnewton/cutlass/releases) पृष्ठ से Cutlass डाउनलोड करके इंस्टॉल करें। Mac और Windows पर उपयोग के लिए तैयार।

हम Cutlass को फिर से लिख रहे हैं ताकि अगला संस्करण बेहतर हो। यह रिपॉज़िटरी वही काम है।
