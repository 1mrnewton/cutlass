# Cutlass

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · **日本語** · [한국어](README.ko.md) · [Español](README.es.md) · [Português](README.pt-BR.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Русский](README.ru.md) · [العربية](README.ar.md) · [हिन्दी](README.hi.md) · [Bahasa Indonesia](README.id.md)

誰でも何でも作れる、無料のオールインワン動画エディタ。

Cutlass には、動画を作るために必要なものがすべて揃っています。AI も最初から入っています。柔軟な編集と、話しかけることができるアシスタント。思い描いた動画を作りましょう。

映像、音声、画像を読み込みます。マルチトラックのタイムラインでトリム、分割、配置ができます。テキスト、ステッカー、図形、エフェクト、トランジションを加えます。色、速度、クロップを調整し、キーフレームでアニメーションさせます。再生して、完成した動画を書き出します。

シンプルに始めて、さらに深く。同じエディタで、すばやいカットも丁寧なカットもできます。

やりたいことを言葉にすることもできます。編集内容を普通の言葉で伝えると、Cutlass がタイムライン上に作ります。あとから変えることも、取り消すこともできます。自分で作業するときも、エディタはそのまま全部使えます。

今日、[リリース](https://github.com/1mrnewton/cutlass/releases) のページから Cutlass をダウンロードしてインストールできます。Mac と Windows ですぐ使えます。

次のバージョンをより良くするため、Cutlass を書き直しています。このリポジトリがその作業です。
