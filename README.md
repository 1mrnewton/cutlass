# Cutlass

Cutlass is a free, open-source video editor in the spirit of CapCut.

You edit on a timeline: cut, trim, arrange, and export. Or you describe the edit and an assistant does it for you. It can remove silences, drop a generated shot in at a time, or assemble a film from a bin of footage. The assistant uses the same edits you would, so every change is visible and can be undone. The editor works on its own if you never use the assistant.

It is one editor for the desktop and for phones.
