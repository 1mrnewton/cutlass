# Cutlass

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Português](README.pt-BR.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · **Русский** · [العربية](README.ar.md) · [हिन्दी](README.hi.md) · [Bahasa Indonesia](README.id.md)

Cutlass — видеоредактор с таймлайном. Рабочий стол, iOS и Android используют один черновик и одну сессию. Жест на любой оболочке становится тем же запросом. Воспроизведение и экспорт видят один кадр для одного черновика и одного момента.

Время в документе — знаковое число микросекунд. Сегмент хранит два интервала в этих единицах. Исходный интервал — используемая часть медиа. Целевой интервал — место на таймлайне.

Если этот перевод и дерево расходятся, опорой служит [английский README](README.md).

## Состояние

Рабочее пространство в начале пути.

| Часть | Состояние |
| --- | --- |
| `cutlass-model` | Черновик: дорожки, сегменты, пулы материалов и время в микросекундах |
| `cutlass-session` | Вставка, перемещение и подрезка как один шаг отмены. Неудачный запрос оставляет черновик как был. Отмена и повтор увеличивают ревизию |
| Остальные крейты | Пустые участники. Они резервируют движок, контейнеры, кодеки, воспроизведение, экспорт и агента |
| `apps/desktop` | Печатает `cutlass` и возвращается. Окно появится позже |
| `apps/ios`, `apps/android` | Появятся в этом дереве позже |

Контейнеры и кодеки — нативный Rust, один крейт на семейство или кодек. На Apple, Windows и Android быстрый путь — медиафреймворки платформы. Linux использует кодеки на Rust и программный предпросмотр.

## Раскладка

```text
apps/desktop/          egui и eframe
crates/                один компонент на крейт
crates/containers/     одно семейство контейнеров на крейт
crates/codecs/         один кодек на крейт
```

Имена крейтов начинаются с `cutlass-`. Двоичный файл рабочего стола компонует крейты напрямую. Оболочки телефона компонуют только `cutlass-ffi`.

## Сборка

Установите стабильный Rust. `rust-toolchain.toml` выбирает канал, Clippy и rustfmt.

```sh
cargo test --workspace
cargo fmt --all -- --check
cargo lint
```

`cargo lint` запускает Clippy по рабочему пространству и отклоняет предупреждения. CI на Ubuntu выполняет эти проверки и `cargo deny`.
