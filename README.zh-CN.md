免费的全能视频编辑器，谁都能用它做出任何作品。

Cutlass 备齐了做一条视频所需的一切，并且内置 AI。编辑灵活，也可以直接和助手说话。做出你心里的那条视频。

导入画面、音频和图片。在多轨道时间线上修剪、分割和排列。加上文字、贴纸、形状、特效和转场。调整颜色、速度和裁剪，再用关键帧做动画。播放，然后导出成片。

从简单开始，也可以再走深一点。同一个编辑器既能快速剪，也能细细打磨。

你也可以直接说出想要的效果。用平常的话描述这次编辑，Cutlass 会把它做到时间线上。你可以再改，也可以撤销。你自己动手时，这个编辑器同样完整。

今天就可以从 [发布页](https://github.com/1mrnewton/cutlass/releases) 下载并安装 Cutlass。可在 Mac 和 Windows 上使用。

我们正在重写 Cutlass，让下一个版本更好。这个仓库就是那项工作。
