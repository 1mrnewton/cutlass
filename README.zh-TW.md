免費的全能影片編輯器，誰都能用它做出任何作品。

Cutlass 備齊了做一支影片所需的一切，並且內建 AI。剪輯靈活，也可以直接和助手說話。做出你心裡的那支影片。

匯入畫面、音訊和圖片。在多軌道時間軸上修剪、分割和排列。加上文字、貼圖、形狀、特效和轉場。調整顏色、速度和裁切，再用關鍵幀做動畫。播放，然後匯出成片。

從簡單開始，也可以再深入。同一個編輯器既能快速剪，也能仔細打磨。

你也可以直接說出想要的效果。用平常的話描述這次編輯，Cutlass 會把它做到時間軸上。你可以再改，也可以復原。你自己動手時，這個編輯器同樣完整。

今天就可以從 [發布頁](https://github.com/1mrnewton/cutlass/releases) 下載並安裝 Cutlass。可在 Mac 和 Windows 上使用。

我們正在重寫 Cutlass，讓下一個版本更好。這個儲存庫就是那項工作。
